# Planutils with NGINX
Basic implementation of planutils with nginx with the objective of loadbalancing the service.

The amount of nodes is manual, you have to phisically modify both the `docker-compose` and `nginx.conf`. Everything is pretty straight forward.

## Run
> Build: `docker-compose build`

> Run: `docker-compose up`

More infos about `docker-compose` can be found in the wiki.
